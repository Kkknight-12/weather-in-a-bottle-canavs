# Third-party code attribution

The fixed-step height/velocity update and cosine drop impulse in index.html are adapted for a CPU Canvas pond from jquery.ripples, src/main.js, Pim Schreurs.
Source: https://github.com/sirxemic/jquery.ripples/blob/d5d1babeb9795ec57eb205fa92d70d46604ede3a/src/main.js
The original WebGL plugin is not bundled; no jQuery dependency is required. The CPU integration, gust field, original-image refraction, rain rendering, UI and procedural audio are project-specific.
